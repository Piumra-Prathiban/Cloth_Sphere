# Cloth Sphere – Garment & Textile Management System

A **Java-based web application** designed to modernize textile and garment industry operations by integrating **production, HR, inventory, sales, and buyer communication** into a unified platform.  
This project is developed as part of the **Software Engineering (SE2030)** module at **SLIIT** using **Spring Boot** and **Microsoft SQL Server 2022**.

---

## 📌 Project Overview
Traditional garment factories often rely on manual systems to manage production schedules, employee activities, stock levels, sales orders, and buyer interactions.  
**Cloth Sphere** aims to solve this by providing a **web-based system** that ensures:
- Real-time visibility
- Seamless inter-departmental coordination
- Enhanced efficiency
- Better buyer engagement

---

## 🎯 Objectives
- Automate workflows across production, HR, sales, and inventory.  
- Enhance communication using shared dashboards and role-based modules.  
- Provide a **Buyer Portal** for product browsing, ordering, and order tracking.  
- Ensure secure, scalable, and maintainable enterprise-level solution.  
- Align with industry standards while applying **Agile (Scrum)** methodology.

---

## 👥 Stakeholders
- **Factory Manager** – Oversees production tasks and staff performance.  
- **HR Manager** – Manages employee records, attendance, and payroll.  
- **Inventory Officer** – Tracks fabric and garment stock levels.  
- **Sales Executive** – Manages orders and customer interactions.  
- **Buyer (Customer)** – Places and tracks orders via buyer portal.  
- **Customer & Product Management Officer** – Maintains products, content, and buyer support.

---

## ⚙️ Major Functional Modules
1. **Production Management** – Scheduling, staff assignment, dashboards, reports.  
2. **HR Management** – Employee records, attendance, leave, and payroll.  
3. **Inventory Management** – Stock tracking, low-stock alerts, reports.  
4. **Sales Order Management** – Order lifecycle handling, tracking, reports.  
5. **Buyer Portal** – Product catalog, order placement, profile management, messaging.  
6. **Customer & Product Management** – Product updates, promotions, buyer support.

### 🔑 Minor Functions
- User registration & role-based login  
- Secure logout  
- Custom dashboards  
- Real-time notifications  
- Search & filter options  
- Data validation & error handling  
- Role-based access control  

---

## 🏗️ System Architecture
- **Backend**: Spring Boot (Java)  
- **Database**: Microsoft SQL Server 2022  
- **Frontend**: Thymeleaf / HTML, CSS, JS (planned)  
- **Design Patterns**: MVC, DAO, Singleton, Factory (where applicable)  
- **Development Methodology**: Agile (Scrum)  

---

## 📊 Non-Functional Requirements
- **Usability** – User-friendly, role-specific dashboards  
- **Security** – Encrypted passwords, role-based authorization  
- **Availability** – 95% uptime during working hours  
- **Scalability** – Modular architecture for future expansions  
- **Maintainability** – Standard code conventions and documentation  
- **Compatibility** – Supports all modern browsers  

---

## 🚧 System Limitations
- Web-only (no mobile app version in this phase)  
- No third-party logistics or payment integration  
- Limited analytics (basic reporting only)  
- Requires stable internet connection  
- English-only interface
